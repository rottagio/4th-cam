# 4TH CAM — Ponte de atualização

Este repositório público existe somente para atualizar instalações antigas do **4TH CAM**.

As versões anteriores à v0.17.3 consultam este endereço. A v0.17.3 transfere o aplicativo para o canal oficial [`4th-cam-releases`](https://github.com/rottagio/4th-cam-releases).

- O código-fonte permanece no repositório privado `4th-cam-desktop`.
- Este repositório não contém código, credenciais ou dados das câmeras.
- Novas versões são publicadas em `4th-cam-releases`.
